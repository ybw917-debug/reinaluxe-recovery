# Hermès asset library

Recommended local structure:

```text
data/research/assets/hermes/
  _shared/
    leather/
    hardware/
    stitching/
    stamps/
    terminology/
  birkin/
    25/
    30/
    35/
  kelly/
    25/
    28/
    32/
  constance/
    18/
    24/
  picotin/
  evelyne/
  mini-lindy/
```

A model-size folder may contain `owner-original/`, `qc-images/`, `seller-shot/`, `supplier-provided/`, `official-reference/`, `community-images/`, `hardware/`, `leather/`, `stitching/`, `structure/`, `measurements/`, and `source-notes/`.

Create only folders that contain real owner-prepared material. Keep private supplier identities in internal source codes or private notes, never in publishable captions or wording. The minimal fixture at `docs/examples/hermes-assets/kelly/28/` demonstrates the manifest layout without creating the full directory tree.
